# 简易量化模拟盘（真正一键启动）

## 怎么用（只要三步）

1. **解压** 这个文件夹到桌面（路径尽量不要有中文）
2. **双击** `start.bat`
3. 弹出窗口后，点 **【开始模拟交易】** 按钮

就这么简单。

---

### 如果双击没反应 / 闪退

- 先安装 Python：https://www.python.org/downloads/  
  **安装时必须勾选 “Add Python to PATH”**
- 安装完再双击 `start.bat`

### 换股票

在弹出的窗口里直接改「股票代码」和「名称」即可，比如：

- 600519  贵州茅台
- 300750  宁德时代
- 000001  平安银行
- 601318  中国平安

### 说明

这是**历史回测 + 模拟盘**，用双均线策略在过去数据上模拟买卖，方便你看策略大概效果。  
**不是实盘交易**，也不会连你的券商账户。
